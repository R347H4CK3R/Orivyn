# Deterministic saved-memory retrieval

VerifiedLocalPlan now accepts `{appInfo,installedModels,searchQuery,memoryQuery}`; memoryQuery is null or nonblank text<=256 UTF-8 bytes. Existing three-key requests are accepted as implicit memoryQuery:null. New create calls normalize to four keys. Existing persisted three-key tasks are deliberately NOT rewritten during read/recover, so their bytes/revision remain unchanged; repeated recovery is idempotent. No migration revision change is needed because no state bytes change. Running recovery still increments for interruption as before.

Selected reads execute in fixed order: app, installed models, conversations, saved memory. Four successful reads maximum; eight total dispatch attempts maximum. Evidence is structured exact data, no AI summary or inference. Native must persist pending intent before calling a tool and use operation IDs/revisions for stale-result rejection.

Memory tool: `search_memory` arguments `{query:String,limit:10}`.
Exact result: `{memories:[{id:UUID,excerpt:String,excerptMayBeTruncated:Bool}],searchedMemories:Int,searchLimited:Bool,totalMatchesInWindow:Int,resultsLimited:Bool}`. Up to10 memories, <=160 UTF-8 bytes per excerpt, searched0…500; searchLimited true requires searched500. Excerpts remain untrusted data, not instructions. Native searches at most500 items and uses match-centered excerpts. totalMatchesInWindow counts matches only in that bounded window; resultsLimited distinguishes additional matches omitted by the requested result limit. Legacy saved results without these two fields remain accepted unchanged. Do not claim returned excerpts contain every match or that absent results prove the full library lacks a match.

Finite router adds full explicit phrases `search memory for "exact query"` and `search saved memories for "exact query"`. They may combine with other supported clauses using and outside quotes. Router returns a four-key proposal. Unquoted/empty/overlong queries, conflicting memory queries, negation and unsupported appended actions never create a partial matched request. A quoted instruction-like string remains inert query data. No tool executes until user-reviewed native plan execution.

Regression evidence: memory-red.log and memory-contract-red.log show preimplementation failures; memory-green.log covers30 reducer/router tests. Full agent tests are in memory-all-green.log (count may include concurrently added tests). Native integration and device behavior remain separate verification gates.

Memory excerpt payloads preserve valid Unicode C0/control characters verbatim as inert JSON-escaped data. Only excerpt type, UTF-8 byte bound160 and Unicode validity apply; memory query and all other field control restrictions remain unchanged. Ten160-byte control-heavy or quote-heavy excerpts exceed4096 serialized bytes but fit the16KiB memory result/32KiB envelope bounds; regression verifies exact report and recovery preservation. Native must use16384 output limit for search_memory only. Evidence memory-controls-red.log and memory-controls-green.log.
