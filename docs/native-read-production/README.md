# Production native read suggestions

The production `LlamaEngine` now calls the native driver under `ORIVYN_NATIVE_TOOLS`, using its existing model/context owner and busy/unload barrier. The file-private gate retains the true owner through detached synchronous decoding. Cancellation can run concurrently; destruction waits for generation return. No second model or llama runtime is introduced.

The optional button in Verified local reads uses the selected, SHA-verified Qwen3 1.7B Q8_0 model to suggest app identity and installed-model reads. The result updates review selections only. Creating and running the deterministic durable plan remain explicit actions using the existing ownership/persistence/execution flow. Search, write and network tools are not offered to the model. Ordinary chat retains its previous path. The existing optional catalog entry, default model, file cap and RAM guidance are preserved.

A synchronous Observation callback cancels the owning task when its heavy-work lease changes. The provider checks admission again after async file verification; the engine checks task cancellation before admission. The host regression deliberately revokes the lease and completes unload while file verification is held, then releases verification. The actual production session/provider rejects the request before inference. Apple JavaScriptCore, persistence and AppModel are host substitutes in this regression; this is not an Apple UI or full-application test.

Reproduce using `scripts/run_native_read_smoke.py --help`. Required inputs are the Swift compiler, pinned llama source, matching native-tools header and single combined native library. Use `--model <verified GGUF>` for real production-engine inference/cancellation/reload/ordinary-chat checks, or `--admission` for the delayed-verification race harness. Both compile the exact production Swift sources with Swift 6. The admission harness uses the workspace's static Swift standard-library workaround for Linux Observation linking.

The feature flag requires a combined runtime exporting the C bridge in the existing `llama` module. No default flag activation, release or preview is included here. Apple linking, Metal, simulator/device memory/lifecycle, SwiftUI execution, wider held-out reliability and general autonomy remain unverified or incomplete. Only two metadata read suggestions are implemented.
