# SideStore installation

There is no released Jarvis-EVO IPA yet. Do not rename source archives or download an unrelated Jarvis package as a substitute.

When a validated release is published:
1. Obtain the versioned unsigned IPA and its SHA-256 from this repository's release.
2. Verify the SHA-256 before importing it.
3. Install and configure SideStore using the current official instructions at https://sidestore.io/ .
4. Import the IPA into SideStore and let SideStore sign it for your Apple account/device.
5. Follow SideStore's refresh, device-pairing and account limits. An unsigned IPA is not directly installable without signing.
6. Launch Jarvis-EVO, install its local model on Wi-Fi, and verify a reply with network connectivity disabled.

The target is iPhone 16 Plus and iOS 26+. Free Apple signing and SideStore have provisioning limits that can change. No Apple credentials belong in this repository or diagnostic reports. Physical-device installation, refresh and LiveContainer compatibility remain unverified until separately tested.
