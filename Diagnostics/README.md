# Internal native capability gates

These test-only projects are not application feature implementations and are not included by the main XcodeGen app target. They are private engineering source, not public distribution assets. No weights or guest disk are committed. Engine assets and original source are fetched only from exact pinned official development sources and verified before use.

VMProof checks actual offline WKWebView BIOS execution and lifecycle. It is not a graphical guest or physical iPhone proof. VisionProof checks ImageIO and the actual pinned multimodal bridge against a real downloaded research model; small-model general image quality remains limited. VisionRuntime builds one pinned llama framework with mtmd rather than linking two independent runtimes. The parent resource admission barrier remains mandatory for future app integration.
